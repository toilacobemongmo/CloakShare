Bảng Tra Nhanh Tệp Cốt Lõi (Architecture Cheat Sheet)

Đường dẫn tệp Công nghệ / Ngôn ngữ Nhiệm vụ cốt tử trong hệ thống CloakShare
core/aes128.c C thuần (FIPS-197) Mã hóa AES-128-CBC 10 vòng, thông lượng cực cao (>580 MB/s).
core/padding.c C thuần (RFC 5652) Đệm PKCS#7 và gỡ đệm thời gian hằng số (chống Padding Oracle).
engine/wrappers/aes_wrapper.py Python + ctypes Cầu nối con trỏ bộ nhớ giữa Python và thư viện C (.dll / .so).
engine/rsa_envelope.py RSA-OAEP 2048-bit Bọc và mở khóa phiên AES (Session Key) bảo mật IND-CCA2.
engine/signer.py RSA-PSS (RFC 8017) Ký số xác suất và kiểm tra toàn vẹn bản mã (lệch 1 bit bị từ chối ngay).
contracts/dPKIRegistry.sol Solidity (EVM) Ánh xạ bất biến: Ethereum Address -> RSA Public Key PEM.
engine/wallet_auth.py Web3 / EIP-191 Tạo và xác thực chữ ký ví Web3 (SIWE challenge), chống Replay (<60s).
broker/memory_store.py Python RAM Store Lưu trữ bytearray trên RAM, 0 ghi ổ cứng, memset ghi đè 0x00 tự hủy.
broker/main.py FastAPI (Uvicorn) Tắt uvicorn.access log, xử lý POST /stage, GET /retrieve kèm TTL loop.
ui/app.py Streamlit Giao diện Web: Chat E2E, CloakDrop Vault, RAM Monitor, Key Studio.
